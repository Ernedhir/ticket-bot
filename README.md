# Running the bot
For booting up the bot:
- Create a virtual environment, activate it and install the `requirements.txt`.
- Create a file named ".env"
- Add two fields called:
    - "DISCORD_API_TOKEN={API_KEY}"
    - "GUILD={GUILD_ID}"
- Run the main.py file!

# Why GUILD?
Currently, bot only supports one server. That is the reason we provide a Guild ID.
